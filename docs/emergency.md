## 🏔️ 高反急救

### 急救步骤

```mermaid
flowchart TB
    A[出现高反症状] --> B{判断严重程度}
    B -->|轻度<br/>头痛、乏力| C[就地休息<br/>吸氧、服药]
    B -->|中度<br/>恶心、呕吐| D[立即吸氧<br/>服用乙酰唑胺]
    B -->|重度<br/>意识模糊| E[立即下撤<br/>就医]
    E --> F{症状缓解?}
    F -->|是| G[继续下撤<br/>低海拔休整]
    F -->|否| H[紧急送医<br/>联系救援]
```

### 急救药物清单

| 药品 | 用途 | 用量 | 注意事项 |
|------|------|------|----------|
| 芬必得 | 高反头痛 | 1 粒 | 不可长期 |
| 乙酰唑胺 | 急性高反 | 125-250mg | 医嘱下使用 |
| 硝苯地平 | 肺水肿 | 10mg 舌下 | 急救用 |
| 地塞米松 | 重度高反 | 4-8mg | 激素，慎用 |
| 红景天 | 预防 | 每日 2-3 次 | 提前 5-7 天 |
| 葡萄糖 | 补能 | 30g 冲水 | 每日 1-2 次 |
| 生理盐水 | 补水 | 500ml 静滴 | 严重时使用 |

### 立即下撤信号

!!! danger "🚨 以下情况立即下撤"
    - 静息时血氧 < 70%
    - 意识模糊
    - 咳粉红色泡沫痰
    - 走路不稳（共济失调）
    - 持续高烧不退
    - 持续呕吐不能进食
    - **每多待 1 小时都是赌命**

## 🚗 车辆故障

### 理想L9 Livis 常见问题

| 问题 | 应急处理 | 后续 |
|------|----------|------|
| **电量耗尽** | 启用强制保电 / 增程器 | 找最近充电桩 |
| **轮胎扎钉** | 补胎工具 / 备胎 | 缓慢行驶到修理厂 |
| **刹车失灵** | 降挡 / 手刹 | 立即靠边 |
| **增程器故障** | 致电 400-686-9999 | 等待救援 |
| **电池故障** | 立即停车 | 等待救援 |
| **车门锁死** | 机械钥匙 | 4S 店处理 |
| **空调故障** | 开窗 | 不影响行驶 |

### 自救步骤

1. **保持冷静**
2. 靠边停车（应急车道或宽阔地）
3. 开启双闪
4. 摆放三角牌（150米外）
5. 人员撤离至护栏外
6. 拨打救援电话

## 🌧️ 恶劣天气应对

### 雨季（5-9月，**本行程 10-11 月避开**）

- 关注天气预报
- 备好雨具
- 减速慢行
- 避让山体滑坡

### 冬季（11-3月，**本行程 11 月初**）

- 关注路面结冰
- **G317 高海拔段可能封路**
- 备好防滑链
- 关注交通管制信息

### 雪天/冰雹

- 减速
- 不急刹车
- 保持安全距离
- 必要时挂防滑链

## 📡 通讯失联

### 信号覆盖

- **G318主段**：基本覆盖
- **G317部分段**：信号差或无
- **无人区**：完全无信号

### 应急通讯

| 设备 | 推荐 | 费用 |
|------|------|------|
| **卫星电话** | 铱星 / 舒拉亚 | 1000+ 元/天 |
| **卫星通信器** | 华为 Mate 60 Pro | 6000+ |
| **北斗短报文** | 部分手机 | 免费 |
| **海事卫星** | 备选 | 贵 |

### 应急方案

1. **告知行程**：出发前向家人报备每日路线
2. **约定频率**：每日固定时间发位置
3. **下载离线地图**：高德、百度
4. **携带应急包**：哨子、反光镜、便携充电
