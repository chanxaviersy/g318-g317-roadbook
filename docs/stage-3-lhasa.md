### Day 15（11/2 周一）拉萨深度休整

**今日主题**：布达拉宫 + 大昭寺 + 八廓街

**行程**：

```
09:00 酒店早餐（早休息后起床）
10:00 **布达拉宫**（必看！）🌟🌟🌟
     - 门票：200元（旺季需提前 1 天预约）
     - 游玩时间：2-3 小时
     - 必看：白宫、红宫、达赖喇嘛灵塔
13:00 午餐（藏餐或中餐）
15:00 **大昭寺** 🌟🌟
     - 门票：85元
     - 游玩时间：1-2 小时
     - 释迦牟尼 12 岁等身像（藏族最珍贵）
     - 必看：金顶、八廓街转经
17:00 **八廓街**（免费）
     - 藏式商业街
     - 工艺品、唐卡、藏银
     - 体验转经
19:00 晚餐
20:00 **布达拉宫广场夜景**（免费）🌟
```

**充电**：

- 🟢 **拉萨理想5C超充**（白天多次补电）

**拉萨住宿推荐**（海拔 3650m）：

- **拉萨瑞吉度假酒店**（1500元/晚，顶级）🌟
- 拉萨香格里拉大酒店（800元/晚）
- 拉萨饭店（400元/晚，老牌）
- 平措康桑酒店（500元/晚）

**今日美食**：

- 🍵 **酥油茶**（藏式早餐必喝）
- 🥘 糌粑
- 🍖 牦牛肉（**玛吉阿米餐厅**，网红）
- 🍶 青稞酒

!!! warning "⚠️ 布达拉宫预约"
    - 旺季需提前 1 天官网预约
    - 每日限流 5000 人
    - 建议提前在"布达拉宫官方平台"预约

!!! tip "💡 高原活动原则"
    - 今日不安排剧烈活动
    - 多喝水（每天 3-4L）
    - 早休息（不超过 22:00）
    - 多监测血氧

### Day 16（11/3 周二）拉萨 → 羊卓雍措 → 拉萨

**路线**：<span class="road-badge road-badge-g349">G349</span> → 曲水 → **岗巴拉山口（4990m）** → 羊湖 → 浪卡子 → 原路返拉萨

**里程**：约 220 km（往返）| **用时**：约 5 小时

**充电**：

- 出发前拉萨5C充满
- 山顶无充电桩

**沿途景点**：

**羊卓雍措** 🌟🌟🌟🌟（西藏三大圣湖之一）

- 门票：60元
- 游玩时间：2-3 小时
- 海拔：4990m（岗巴拉山口）
- 必拍：岗巴拉观景台俯瞰羊湖

**羊湖看点**：

- 湖水呈现多层蓝色（光合作用 + 矿物质）
- 岗巴拉山垭口观景台
- 湖畔藏式村庄
- 浪卡子县午餐（海拔 4450m）

**行程时间表**：

```
07:30 早餐
08:00 拉萨出发
10:00 岗巴拉山口（拍照 30 分钟）🌟
11:00 羊湖观景台（拍照 1 小时）
12:30 浪卡子县午餐
14:00 返回拉萨
16:30 抵达拉萨
```

**今日美食**：

- 🍖 浪卡子牦牛肉
- 🥛 酥油茶

!!! warning "⚠️ 羊湖高反"
    - 岗巴拉山口海拔 4990m，**接近极高反风险**
    - 停留时间不超过 1 小时
    - 慢走、不奔跑
    - 备好氧气

### Day 17（11/4 周三）拉萨 → 日喀则

08:00 拉萨出发
13:00 抵达日喀则
13:30 午餐

18:00 日喀则古城闲逛
19:30 晚餐

### Day 18（11/5 周四）日喀则 → 珠峰大本营 → 定日 / 日喀则

**路线**：<span class="road-badge road-badge-g318">G318</span> → 拉孜 → **嘉措拉山口（5248m）** → 珠峰保护区 → 珠峰大本营

**里程**：约 600 km（往返）| **用时**：约 10-12 小时

**充电**：

- 🟢 **日喀则环城路站**（理想5C，出发前充满）
- 定日县城第三方桩（应急）

**沿途景点**：

**嘉措拉山口** 🌟🌟（全程最高点）

- 海拔 5248m
- 离珠峰最近的垭口
- 风大、可能下雪

**珠穆朗玛峰大本营** 🌟🌟🌟🌟🌟（世界之巅！）

- 门票：180元（珠峰自然保护区）
- 车辆进山费：120元
- 观光车：120元
- 游玩时间：1-2 小时
- 必看：珠峰观景台、绒布寺、珠峰测量纪念碑
- 珠峰海拔：8848.86m

**行程时间表**：

```
05:30 早起，早餐
06:00 日喀则出发
09:30 拉孜午餐
10:00 嘉措拉山口（拍照 20 分钟）
12:00 抵达珠峰大本营
13:00 绒布寺 + 观景台
14:30 返程
20:00 抵达日喀则（或定日）
```

!!! danger "⚠️ 珠峰段风险"
    - 嘉措拉山口 5248m，**全程最高点**
    - 珠峰大本营海拔 5200m
    - **务必携带氧气袋**（每人 1 袋+）
    - 监测血氧（< 80% 立即下撤）
    - 路面颠簸，慢速行驶
    - 边防证必带

**住宿**：

- 选择 1：返回日喀则（舒适）
- 选择 2：定日县城（节省时间，但住宿条件一般）

**今日美食**：

- 🍖 珠峰牦牛肉
- 🍵 酥油茶

!!! tip "💡 珠峰小贴士"
    - **珠峰观景台** 实为加乌拉山观景台（5210m），可远眺 4 座 8000m+ 雪山
    - 真正的珠峰大本营已封闭
    - 最佳拍照：上午光线（下午多云）

    - 当雄县住宿：海拔 4300m
    - 但本行程选择 G317 主线，舍弃纳木措
