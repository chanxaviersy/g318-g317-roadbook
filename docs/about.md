# 关于本路书

## 📚 路书简介

这是一份为 **理想L9 Livis 车主** 量身定制的川藏大环线电子路书，详细记录 30 天、8,800 公里、穿越 14 条国家高速和 5 条国家国道的 G318 进 G317 出川藏大环线。

---

## 🚗 行程概要

| 维度 | 详情 |
|------|------|
| **起止** | 深圳皇岗 ⇄ 深圳皇岗 |
| **总天数** | 30 天 |
| **总里程** | 约 8,800 公里 |
| **主线道路** | 🟢 G318 川藏南线（去程） + 🟣 G317 川藏北线（回程） |
| **最高点** | 嘉措拉山口 5248m（珠峰段） |
| **主要城市** | 深圳、广州、桂林、贵阳、成都、康定、理塘、稻城、芒康、然乌、林芝、拉萨、日喀则、那曲、昌都、德格、色达、马尔康、重庆、张家界、长沙 |
| **充电网络** | 理想5C 12+ 座（川藏南线）、国网桩为主（川藏北线） |

## 🛠️ 技术栈

本路书使用以下开源技术构建：

- **[MkDocs](https://www.mkdocs.org/)** - 静态网站生成器
- **[Material for MkDocs](https://squidfunk.github.io/mkdocs-material/)** - 主题
- **[Mermaid](https://mermaid.js.org/)** - 流程图、时序图
- **[Vega-Lite](https://vega.github.io/vega-lite/)** - 数据可视化
- **Markdown** - 内容创作
- **Python** - 部署脚本

### 特色

- 📱 **响应式设计**：手机/平板/电脑自适应
- 🌗 **明暗主题**：跟随系统自动切换
- 🔍 **全文搜索**：支持中文分词
- 📊 **交互式图表**：海拔、里程、道路分布
- 🗺️ **流程图**：清晰呈现路网拓扑
- 🔗 **深度链接**：永久URL，便于分享
