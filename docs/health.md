## 📊 高反分级与应对

### 高反分级标准

| 等级 | 血氧饱和度 | 症状 | 应对 |
|------|------------|------|------|
| **正常** | > 90% | 无明显不适 | 正常活动 |
| **轻度** | 80-90% | 头痛、乏力、失眠、食欲减退 | 休息、吸氧、葡萄糖 |
| **中度** | 70-80% | 头痛加重、恶心、呕吐、心慌 | 立即吸氧、停止上升、必要时下撤 |
| **重度** | 60-70% | 意识模糊、肺水肿征兆 | **立即下撤**、送医 |
| **危急** | < 60% | 昏迷、肺水肿/脑水肿 | **紧急救援、生命危险** |

!!! danger "🚨 立即下撤信号"
    - 静息时血氧 < 70%
    - 出现意识模糊
    - 咳粉红色泡沫痰（肺水肿）
    - 走路不稳（脑水肿）
    - **这种情况下，每多待 1 小时都是赌命**

### 氧气种类

| 类型 | 容量 | 续航 | 适用 |
|------|------|------|------|
| **便携式氧气罐** | 1-2L | 30-60分钟 | 应急补氧 |
| 家用制氧机 | — | 持续 | 酒店内使用 |
| **氧气袋** | 42L | 多次 | **最推荐**（可灌可吸） |

- 拉萨：城关区多家诊所、医院

- 那曲：藏医院
- 沿途酒店：很多高档酒店可提供制氧机租赁

## 🍎 饮食与作息建议

### 饮食原则

!!! tip "✅ 推荐"
    - 高碳水：面条、米饭、馒头
    - 高糖：巧克力、糖水、蜂蜜
    - 易消化：粥、汤面、蒸蛋
    - 维生素：新鲜蔬果
    - 充足饮水：每天 3-4L

!!! danger "❌ 避免"
    - 酒精（致命！）
    - 油腻食物
    - 暴饮暴食
    - 浓茶浓咖啡
    - 过量饮水（一次>1L）

### 作息建议

| 时段 | 建议 |
|------|------|
| 起床 | 不超过 8:00，给身体适应时间 |
| 早餐 | 7:30-8:30，多糖多碳 |
| 午餐 | 12:00-13:00 |
| 午休 | 13:30-15:00（关键）|
| 晚餐 | 18:30-19:30 |
| 入睡 | 不超过 22:00（避免失眠加重高反）|
| 避免 | 剧烈运动、长途步行、过度兴奋 |

## 🏃 阶梯式适应策略

### 海拔上升原则

!!! info "📏 关键原则：500米法则"
    每日上升 **不超过 500-800米** 睡眠海拔。本行程的安排：

    ```
    500m（桂林）→ 900m（贵阳）→ 1500m（泸州）→ 500m（成都）
    → 2560m（康定）→ 4014m（理塘）✅ 上 1454m（较大）
    → 2900m（亚丁）✅ 下降 1114m（休整）
    → 3750m（稻城）→ 3875m（芒康）→ 3280m（八宿）→ 2750m（波密）
    → 2900m（林芝）→ 3650m（拉萨）→ 4500m（那曲）✅ 上 850m
    → 4000m（索县）→ 3500m（昌都）→ 3260m（德格）✅ 持续下降
    → 4000m（色达）→ 2600m（马尔康）✅ 大幅下降
    ```

    **理塘跳到 4014m 是一次风险点**，建议：
    - 康定时充分休整 1 天（其实本行程只 1 晚，可以接受）
    - 到理塘后多喝水、多休息
    - 当晚不要洗澡

## ⚕️ 高反口诀

!!! quote "📜 高原反应"三不"原则"
    1. **不洗澡**（高反初期洗澡加重）
    2. **不喝酒**（致命）
    3. **不剧烈运动**（慢走为主）

!!! quote "📜 高原反应"三多"原则"
    1. **多喝水**（每天 3-4L）
    2. **多休息**（睡饱睡足）
    3. **多观察**（监测血氧）

!!! quote "📜 高原反应"三早"原则"
    1. **早就医**（不适立即评估）
    2. **早吸氧**（血氧 < 90% 立即吸氧）
    3. **早下撤**（中度高反立即下撤）

## 🧘 高反自测工具

### Lake Louise 评分表

| 症状 | 分数 |
|------|------|
| 头痛 | 0-3分 |
| 消化道症状 | 0-3分 |
| 疲劳/虚弱 | 0-3分 |
| 头晕/头昏 | 0-3分 |
| 睡眠障碍 | 0-3分 |
| **总分** | **0-15分** |

- **0-2分**：正常
- **3-5分**：轻度高反
- **6-9分**：中度高反
- **10+ 分**：重度高反，需立即下撤
