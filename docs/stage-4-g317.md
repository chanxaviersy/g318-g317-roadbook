## ⚡ G317 充电策略详解

### 三段难点

```mermaid
flowchart LR
    A[拉萨<br/>5C] -->|450km<br/>G109| B[那曲<br/>国网120kW]
    B -->|750km<br/>G317<br/>⚠️艰难| C[昌都<br/>国网250kW]
    C -->|340km<br/>⚠️稀缺| D[德格<br/>第三方6枪]
    D -->|380km<br/>雀儿山| E[甘孜<br/>国网120kW]
    E -->|610km| F[马尔康<br/>🌟国网600kW]
```

### 关键原则

1. **每站必充**：G317 充电桩少且不稳定
2. **关注App**：理想、特来电、e充电实时状态
3. **应急方案**：备理想随车充（220V 慢充，7kW）
4. **避雷暴**：高原天气多变
5. **夜间充电**：抵达酒店后立即充
